# Code of Conduct

## Our pledge

We want participation in this project to be a respectful, harassment-free experience
for everyone, regardless of background or experience level.

## Expected behaviour

- Be respectful and constructive.
- Accept feedback gracefully and give it kindly.
- Focus on what is best for the project and its community.

## Unacceptable behaviour

- Harassment, insults, discrimination or personal attacks.
- Publishing others' private information without permission.
- Any conduct that would reasonably be considered inappropriate in a professional setting.

## Enforcement

Maintainers may remove, edit or reject contributions that violate this code of conduct.
To report a problem, open a private report through GitHub or contact the maintainer
via the email listed on their GitHub profile.

This text is a condensed adaptation inspired by the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
